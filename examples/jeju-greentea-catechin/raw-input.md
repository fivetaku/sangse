# Raw Input — 제주숲 녹차 카테킨 캡슐 (가상 상품)

> ⚠️ **이 상품·브랜드·수치는 전부 sangse 스킬 시연용 가상 설정이다.** 실제 판매·인증·심의 사실이 아니다. 인터뷰(Step 2)는 가상 상품 규칙에 따라 생략하고 아래 값을 "가상 설정"으로 기록한다.

## 사용자가 준 정보 (가상)

- 상품: 제주숲 녹차 카테킨 캡슐. 제주 서귀포 유기농 녹차에서 추출한 녹차추출물 캡슐. 500 mg × 60캡슐 (1개월분, 1일 2캡슐).
- 지역성: 제주 서귀포 화산토 다원, 유기농 인증 다원 3곳 계약(가상). 봄 첫물차 잎만 사용(가상).
- 인증: 건강기능식품 인증마크 취득(가상). 기능성 원료: 녹차추출물(고시형). 1일 섭취량당 카테킨 400 mg (가상 설정, 고시 범위 300~1,000 mg 내).
- 고시형 기능성 문구: "항산화에 도움을 줄 수 있음", "체지방 감소에 도움을 줄 수 있음". (이 두 문구만 사용. "다이어트" 단어는 쓰지 않기로 함)
- 표시·광고 사전심의: 완료(가상, 심의필 번호 없음 → 플레이스홀더)
- 타겟(창업자 초안): "건강 관리하는 분" → 좁혀야 함. 실제로 팔고 싶은 사람: 하루 종일 앉아 일하고 저녁에 배달 음식을 자주 먹는 30대 재택근무자. 녹차는 하루 3잔 우려 마시기 번거로워 포기한 사람.
- 고객이 얻는 변화(창업자 표현): "아침 물 한 잔에 캡슐 2개. 녹차 우릴 시간 없이 카테킨은 챙긴다."
- 가격: 정가 42,000원. 첫 구매 10% 할인 37,800원 (기한 없음). 정기구독 시 15%.
- 환불: 미개봉 7일 이내 전액 환불. 개봉 후는 환불 불가(가상 정책 — 대신 10캡슐 샘플팩 2,900원 별도 판매).
- 섭취법: 1일 2캡슐, 아침 식후 물과 함께. 카페인 함유(1일 섭취량당 약 20 mg — 가상) → 카페인 민감자 주의.
- 섭취 시 주의: 카페인 민감자·임산부·수유부·어린이·질환자·약 복용자는 전문가 상담. 간 질환자 주의(라벨 기준 확인 필요). 이상 사례 발생 시 섭취 중단.
- 구성품: 캡슐 60정 병 + 휴대용 7일 케이스 + 제주 다원 엽서.
- 사례·후기: 신제품, 없음. 실물 사진: 없음.
- 플랫폼: 네이버 스마트스토어. 유입: 검색("녹차추출물", "카테킨") 유입 위주.
- 톤: 담백한 존댓말. 색: 짙은 녹색 + 화이트.
- 기존 방식의 한계(창업자 진술): 녹차 티백은 하루 3잔 챙기기 어렵고 카테킨 양을 알 수 없음, 해외 직구 카테킨은 함량 표기가 제각각, 녹차 분말은 물에 잘 안 풀림.
