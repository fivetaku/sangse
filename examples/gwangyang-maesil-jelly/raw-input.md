# Raw Input — 광양골 매실 데일리젤리 (가상 상품)

> ⚠️ **이 상품·브랜드·수치는 전부 sangse 스킬 시연용 가상 설정이다.** 실제 판매·인증·심의 사실이 아니다. 인터뷰(Step 2)는 가상 상품 규칙에 따라 생략하고 아래 값을 "가상 설정"으로 기록한다.

## 사용자가 준 정보 (가상)

- 상품: 광양골 매실 데일리젤리. 전남 광양 매실로 만든 매실추출물 스틱젤리. 20 g × 30포 (1개월분).
- 지역성: 광양은 국내 매실 주산지로 알려짐. 계약 재배 농가 8곳, 섬진강변 재배(가상). 6월 수확분만 사용(가상).
- 인증: 건강기능식품 인증마크 취득(가상). 기능성 원료: 매실추출물(고시형, 피로 개선 원료로 등재). 1일 섭취량당 지표성분 함량: [가상 설정 미정 — 실제 제품이면 라벨 기준. 플레이스홀더 처리]
- 고시형 기능성 문구: "피로 개선에 도움을 줄 수 있음". (이 문구만 사용)
- 표시·광고 사전심의: 완료(가상, 심의필 번호 없음 → 플레이스홀더)
- 타겟(창업자 초안): "피곤한 현대인 모두" → 좁혀야 함. 실제로 팔고 싶은 사람: 새벽 운동 뒤 출근하는 20~30대 직장인. 운동 후 단 것이 당기는데 죄책감이 드는 사람.
- 고객이 얻는 변화(창업자 표현): "운동 끝나고 샤워 전에 한 포. 달콤한데 설탕 젤리 대신 매실이라 마음이 편하다."
- 가격: 정가 36,000원. 런칭 15% 할인 30,600원, 2026-09-30까지. 2박스 구매 시 무료배송.
- 환불: 미개봉 7일 이내 전액 환불. 개봉 후 맛 불만 시 첫 구매 1회 한정 남은 수량 반품 환불(가상 정책).
- 섭취법: 1일 1포, 운동 후 또는 오후. 상온 보관, 냉장 시 젤리 식감이 단단해짐.
- 섭취 시 주의: 알레르기 체질은 원재료 확인. 임산부·수유부·어린이·질환자·약 복용자는 전문가 상담. 이상 사례 발생 시 섭취 중단.
- 구성품: 젤리 30포 + 지퍼백 파우치 + 운동 기록 카드(30칸) + 광양 농가 리플릿.
- 맛: 새콤달콤, 무설탕(알룰로스 사용 — 가상), 1포 25 kcal(가상).
- 사례·후기: 신제품, 없음.
- 실물 사진: 없음.
- 플랫폼: 네이버 스마트스토어. 유입: 인스타 광고 콜드 유입 위주.
- 톤: 친근한 존댓말. 색: 연한 연두 + 크림.
- 기존 방식의 한계(창업자 진술): 매실청은 병째라 휴대 불가·당 함량 높음, 에너지젤은 인공 향이 강함, 홍삼은 운동 직후 먹기엔 무겁다.
