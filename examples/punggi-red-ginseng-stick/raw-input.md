# Raw Input — 풍기골 홍삼 데일리스틱 (가상 상품)

> ⚠️ **이 상품·브랜드·수치는 전부 sangse 스킬 시연용 가상 설정이다.** 실제 판매·인증·심의 사실이 아니다. 인터뷰(Step 2)는 가상 상품 규칙에 따라 생략하고 아래 값을 "가상 설정"으로 기록한다.

## 사용자가 준 정보 (가상)

- 상품: 풍기골 홍삼 데일리스틱. 경북 영주 풍기 6년근 홍삼농축액 스틱. 10 mL × 30포 (1개월분).
- 지역성: 풍기는 조선시대 인삼 재배지로 알려진 곳. 계약 재배 농가 12곳, 소백산 자락 재배(가상).
- 인증: 건강기능식품 인증마크 취득(가상). 기능성 원료: 홍삼. 1일 섭취량당 진세노사이드 Rg1+Rb1+Rg3 합 7 mg (가상 설정, 고시 규격 3~80 mg 범위 내).
- 고시형 기능성 문구(홍삼): "면역력 증진에 도움을 줄 수 있음", "피로 개선에 도움을 줄 수 있음". (이 두 문구만 사용. 다른 홍삼 기능성은 표기하지 않기로 함)
- 표시·광고 사전심의: 한국건강기능식품협회 심의 완료 및 심의필 번호 보유(가상 — 실제 번호 없음 → 플레이스홀더)
- 타겟(창업자가 준 초안): "건강 챙기고 싶은 모든 분" → 좁혀야 함. 창업자가 실제로 팔고 싶은 사람: 오후만 되면 커피로 버티는 30대 야근 직장인.
- 고객이 얻는 변화(창업자 표현): "아침에 스틱 하나 짜먹고 하루 시작. 홍삼차 우리는 번거로움 없이 출근길에 챙길 수 있다."
- 가격: 정가 49,000원. 런칭 기념 20% 할인 39,200원, 2026-09-30까지. 정기구독 시 추가 10%.
- 환불: 미개봉 7일 이내 전액 환불. 개봉 후 맛·식감 불만 시 첫 구매 1회 한정 남은 수량 반품 환불(가상 정책).
- 섭취법: 1일 1포, 아침 공복 또는 식후. 상온 보관. 냉장 시 더 진한 맛.
- 섭취 시 주의: 알레르기 체질·특이체질은 성분 확인. 임산부·수유부·어린이·질환자·약 복용자는 전문가 상담. 이상 사례 발생 시 섭취 중단. (표시기준상 필수 문구는 실제 라벨 기준으로 확인 필요)
- 구성품: 스틱 30포 + 종이 보관 케이스 + 섭취 체크 카드(30칸) + 풍기 농가 소개 리플릿.
- 사례·후기: 신제품, 없음. 체험단 모집 계획 없음.
- 실물 사진: 없음 (이미지는 생성).
- 플랫폼: 네이버 스마트스토어.
- 톤: 담백한 존댓말. 색: 진한 적갈색 + 아이보리.
- 기존 방식의 한계(창업자 진술): 홍삼 파우치는 냉장 보관·비린 향이 부담, 홍삼정은 티스푼으로 떠먹어 출근길에 못 챙김, 선물용 대용량은 혼자 다 못 먹음.
