# Raw Input — 또박 손글씨 4주 온라인 클래스 (가상 서비스, 구독 랜딩)

> ⚠️ 이 서비스·수치는 전부 sangse 시연용 가상 설정이다. 인터뷰는 생략한다.

## 사용자가 준 정보 (가상)
- 상품: 또박 손글씨 4주 온라인 클래스. 주 2회 영상(총 8강, 각 15분) + 연습장 PDF 4권 + 주 1회 피드백(사진 제출).
- 오퍼(가상): 정가 79,000원 → 얼리버드 49,000원(선착순 100명, 2026-09-30까지), 2차 59,000원(10-01~10-15), 이후 정가. 월 구독 옵션 19,000원(모든 클래스 무제한, 첫 달 50%).
- 혜택 리스트(가상): 01 평생 소장 02 연습장 PDF 4권 03 주 1회 피드백 04 수료증 05 재수강 무료 06 커뮤니티 07 7일 환불 보장.
- 근거(가상): 수강생 1,240명, 평점 4.8/5(후기 312개), 4주 완주율 71% — 전부 가상 수치. 후기 2개(가상): "글씨가 정돈돼서 메모가 즐거워요"(직장인 3년차), "아이 알림장 쓰기가 편해졌어요"(주부).
- 타겟: 글씨 콤플렉스가 있는 20~40대 직장인·학부모.
- 변화: "4주 뒤 손글씨 메모를 부끄럽지 않게 남긴다."
- 진행: 1주 기본 획 → 2주 자음·모음 → 3주 문장 → 4주 나만의 서체.
- 환불: 결제 후 7일 이내, 2강 이하 수강 시 전액 환불.
- 플랫폼: 자사 랜딩(웹). 톤: 친근한 존댓말. 색: 아이보리 + 오렌지 포인트.
- 기존 한계(창업자): 학원은 시간 고정, 유튜브는 피드백이 없다.
