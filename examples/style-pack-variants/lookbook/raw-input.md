## 사용자가 준 정보 (가상)
- 상품: 도담 오버핏 린넨 셔츠. 프랑스산 린넨 100%, 남녀 공용 S/M/L/XL. 색상 6종(화이트·샌드·세이지·네이비·차콜·테라코타).
- 소재·제작: 린넨 100%(가상), 국내 봉제(가상), 워싱 가공으로 첫 착용부터 부드러움. 실측(가상): M 기준 총장 74 cm, 가슴 60 cm, 어깨 52 cm, 소매 58 cm.
- 모델 정보(가상): 남성 모델 키 181 cm 체중 72 kg → L 착용, 여성 모델 키 165 cm → S 착용.
- 타겟: 여름 출근·주말 여행에 한 벌로 다 입고 싶은 20~30대. 룩: 오버핏, 소매 롤업, 앞단 인·아웃 모두 가능.
- 고객이 얻는 변화: "땀 차는 여름에 다림질 없이 걸치기만 해도 정돈돼 보인다."
- 세탁·관리: 찬물 단독 세탁, 건조기 금지, 린넨 특성상 구김·올 풀림은 자연스러운 특성.
- 가격: 59,000원. 할인·기한 없음.
- 환불: 미착용·택 부착 상태 7일 이내 교환·반품 가능. 세탁·착용 후 불가.
- 사례·후기: 신제품, 없음. 실물 사진: 모델 착용 컷 촬영 예정(가상 — 이미지는 생성).
- 플랫폼: 패션 플랫폼 입점 + 자사몰. 톤: 짧은 명사구·구어. 색: 화이트 배경 + 세이지 포인트.
- 기존 방식의 한계: 폴리 셔츠는 땀이 차고, 얇은 면 셔츠는 다림질이 필수였다.
