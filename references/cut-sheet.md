# 컷 시트 형식 — `cuts.md` + `legal.md`

> sangse의 기본 산출물. 근거는 `reference-patterns.md`(컬리·쿠팡·자사몰 상세는 폭 1000 이미지 컷의 세로 나열이고 카피는 이미지 안에 있다). 8질문 순서는 그대로 지키되, **단위가 "섹션 문단"에서 "컷 이미지"로 바뀐다.**

## 1. cuts.md 문법

```markdown
# {제품명} 컷 시트
platform: smartstore        # web | smartstore | kmong | funding
width: 1000                 # 스마트스토어 등록 시 860으로 축소
brand: primary=#7A2E1D neutral=#F3EBDD,#D8C4A2,#F0F0F0 accent=#C8102E
tone: 담백한 존댓말
anchor: C02                 # 스타일 앵커 컷(보통 제품명 히어로). 나머지는 --ref로 물린다

## C01 · K3 · Q1 · h=1350
headline: 오후 3시,|커피 대신 한 포          # '|'가 행 구분. 템플릿 headline_max 이내
sub: 점심 지나면 커피 없이 못 버티는 날이 이어지시나요
body: |
  출근길 가방에 넣고 짜 먹는 10 mL 한 포
  홍삼정 티스푼은 서랍에 두셔도 됩니다
tags: #출근길 #오후3시 #한포           # 선택
persona: [34세, 야근 잦은 직장인]        # K3 전용
visual: 34세 직장인 반신 라인 일러스트(우), 스틱 2개(좌), 아이보리 브러시 사선
bg: #FFFFFF
text_pos: 좌상
footnote: 1일 1회 1포 섭취 제품입니다    # 각주(법정 가드). 선택
image: images/c01.png                   # 생성 후 기록. 없으면 텍스트 플레이스홀더 렌더
```

- 컷 헤딩: `## C{두 자리} · {템플릿 ID} · {Q1~Q8|brand} · h={높이px}`. 템플릿 ID와 슬롯 한도는 `assets/cut-templates.json`.
- `headline`의 `|`는 행 구분. 행당 글자 수와 행 수를 템플릿에 맞춘다(감성 헤드 2행 각 5~9자).
- `body`는 `|` 뒤 들여쓴 여러 줄. 줄당 `line_max` 이내, 줄 수 `body_lines_max` 이내.
- `visual`은 이미지 생성 브리프의 피사체 델타. 스타일·조명·색은 앵커 컷에서 상속.
- `footnote`는 이미지 하단 각주(18~20px). 법정 가드 문구 전용.
- 플레이스홀더는 값 자리에 그대로 `[자료 필요: …]`.

## 2. legal.md — HTML로 남기는 블록

```markdown
## 기능성·섭취 정보          # 건기식: 고시 문구 원문, 1일 섭취량·방법, 지표성분
## 섭취 시 주의사항          # 라벨 원문 불릿
## 제품 상세정보             # 2열 표: 제품명/포장단위/식품유형/의약품 아님/제조원/소비기한/심의필/이상사례 신고/소비자보상/고객센터
## 영양·기능정보             # 표
## 원료명 및 함량
## 배송·교환·환불            # 실제 정책 그대로 (전자상거래법 7일 기준선 이상)
## 상품정보제공고시          # 플랫폼 입력란 대응
```
비어 있는 항목은 `[자료 필요: …]`로 둔다. 레퍼런스(컬리)는 이 블록도 이미지로 넣었지만 sangse는 정확도·수정성·검색 때문에 HTML을 기본으로 한다. 단일 이미지 제출이 강제되면 `--legal-as-image`로 텍스트 컷을 추가 생성한다.

## 4. 텍스트 안전 규칙 (gpt-image-2 실측 한계 반영)

- 이미지 안에 넣는 글자: 헤드 65~75px / 섹션 헤드 42~50 / 본문 22~26 / 각주 18~20 (폭 1000 기준). **18px 미만 글자는 넣지 않는다** — 스마트스토어 모바일에서 폭 360으로 축소되면 6~7px가 되어 판독 불가.
- 컷당 텍스트 10줄 이하. 가격·전화번호·심의번호·영양 수치·차트 값은 이미지에 넣지 않는다(→ legal.md).
- 헤드라인·고시 문구는 생성 후 **Read로 글자 검수**. 자모 오류 시 폰트·크기를 명시해 재생성 1~2회.
- 인물은 얼굴 없는 라인 일러스트 또는 뒷모습·손만(초상권·가짜 후기 인상 방지).

## 5. 브랜드 앵커 규칙

1. C01(제품명 히어로)을 먼저 생성해 색·조명·재질을 확정한다. Read로 확인 후 `anchor:`에 기록.
2. 나머지 컷은 전부 `--ref {anchor}`로 생성하고, 프롬프트에서 스타일 서술을 걷어낸 뒤 "attached reference의 색·조명·재질 유지 + 아래 레이아웃·텍스트만"으로 쓴다.
3. 배경색은 컷마다 바꾼다(레퍼런스 리듬: 브랜드색 → 흰 → 탄 → 크림 → 탄 → 브라운/오렌지 → 연회색). `bg:`에 명시.

## 6. HTML 조립

`assemble_html.py`는 `cuts.md`가 있으면 컷 모드로 동작한다: 각 컷의 `image:`를 폭 100%로 세로 나열(여백 0), 이미지가 없는 컷은 텍스트 플레이스홀더 블록(배경색·헤드·본문)으로 렌더, 마지막에 `legal.md`를 HTML 표·불릿으로 붙인다. 폭은 platform에 따라 860/720.
