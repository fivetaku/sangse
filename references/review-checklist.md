# 검수 체크리스트 — 의심 많은 고객의 눈

> 영상의 검수법: 창업자 눈으로 읽지 않는다. 의심 많은 고객 페르소나에 메소드 연기처럼 몰입해 **모든 문장 뒤에 "그래서 나한테 뭐가 좋은데?"를 붙여** 읽는다. 답이 없는 문장은 고객 결과값으로 번역하거나 삭제한다.

## 1. 문장 단위 검수 (copy.md 전체)

각 문장에 대해 세 갈래로 판정한다.

| 판정 | 조건 | 조치 |
|---|---|---|
| **통과** | "그래서 나한테 뭐가 좋은데?"에 문장 자체가 답한다 | 유지 |
| **번역** | 사실은 맞지만 창업자 언어다 (스펙·경력·최초·기능명) | `[스펙] 덕분에 당신은 [구체 이득]` 꼴로 재작성 |
| **삭제** | 구매 결정에 영향이 없다 (인사말, 회사 연혁, 형용사 나열) | 제거 |

수정한 문장은 `review-log.md`에 `원문 → 수정문 (판정)` 한 줄씩 기록한다. 이 로그가 A/B 테스트의 가설 목록이 된다.

## 2. 구조 체크 C1~C10 (전부 통과해야 완료)

기계 판정 가능한 항목(C1·C2·C3·C7·C8·C9·C10·이미지 실존)은 `scripts/check_copy.py`가 돌린다 — 손으로 다시 세지 말고 `qa/check_copy.json`을 읽는다. C4·C5·C6은 사람/에이전트 판단이며 게이트 2(`verification.md`)의 규제 심사관·의심 많은 고객이 담당한다.

| # | 기준 | 확인 방법 |
|---|---|---|
| C1 | Q1~Q8 섹션이 전부 존재하고 순서가 프레임워크와 같다 | `## Q1`~`## Q8` 헤딩 8개 확인 |
| C2 | Q1 첫 문장에 제품명·"AI 기반"·"국내 최초"·"올인원"·"혁신"·"누구나"가 없다 | 금지어 grep |
| C3 | 모든 수치·후기·사례·고유명사가 `raw-input.md` 또는 사용자 답변에 있다 | 숫자 추출 후 원문 대조. 없으면 삭제 또는 `[자료 필요]` |
| C4 | Q7 환불·보증 문구가 사용자가 준 정책과 일치하고 "100% 보장"류 미확인 문구가 없다 | 원문 대조 |
| C5 | Q8에 사용자가 주지 않은 기한·할인이 없다 (가짜 긴급성 금지) | 원문 대조 |
| C6 | 타겟이 좁다: Q1을 읽고 "이건 내 얘기가 아니네"라고 걸러지는 고객이 실제로 있다 | 배제되는 고객 유형을 한 줄로 쓸 수 있는가 |
| C7 | 각 섹션 헤드라인 20자 이내, 본문 2~5문장 | 길이 확인 |
| C8 | CTA 문구가 "구매하기"류 행동 단독이 아니라 행동+결과다. 같은 CTA가 Q2·Q4·Q8에 반복된다 | CTA 확인 |
| C9 | 규제 업종이면 `compliance.md` §5 항목 전부 통과 (고시 문구 일치, 질병·의약품 용어 없음, 후기가 효능 암시 안 함, 필수 표시 슬롯) | 금지어 grep + 문구 대조 |
| C10 | Q6에 사양 표(성분·용량·규격)가 있고, 물성 상품이면 Q7-FAQ가 실제 문의 기반이거나 `[자료 필요]`다 | 구조 확인 |

## 3. 이미지 검수 (이미지 단계가 실행된 경우)

| # | 기준 |
|---|---|
| I1 | 이미지 내 텍스트는 12자 이내 헤드라인 또는 숫자만. 본문·가격·전화번호·날짜는 이미지에 넣지 않고 HTML 텍스트로 배치 |
| I2 | 한글이 깨졌으면 폰트·크기 명시해 1~2회 재생성. 그래도 실패하면 텍스트 없는 버전으로 재생성 |
| I3 | 시리즈 이미지가 첫 장(앵커)과 같은 스타일·색감인가 |
| I4 | 사용자가 준 실물 스크린샷이 있으면 Q4는 생성 이미지 대신 실물을 쓴다 |

## 4. HTML 검수

| # | 기준 |
|---|---|
| H1 | 모바일 폭(390px)에서 가로 스크롤 없이 렌더된다 |
| H2 | 이미지 경로가 index.html 기준 상대경로로 실제 존재한다 (assemble 스크립트가 경고 출력) |
| H3 | `[자료 필요]` 플레이스홀더가 남아 있으면 HTML에도 노란 박스로 보인다(숨기지 않는다) |

## 5. 완료 보고에 반드시 포함할 것

1. 채우면 완성되는 항목 표 (플레이스홀더 목록)
2. review-log 요약: 번역/삭제 건수와 대표 예 2개
3. 경고 한 줄: "가격·환불·기한 문구는 실제 결제·법적 책임과 연결됩니다. 퍼블리시 전 직접 확인하세요."
4. 다음 A/B 제안 1개: 먼저 바꿔볼 상단 섹션 가설
