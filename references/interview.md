# 제품 인터뷰 — 불확실성 기반 질문 은행

> 카피를 쓰기 전에 **요청에 남은 불확실성만** 골라 묻는다. 추론 가능한 것은 묻지 않고 기본값으로 진행하되 첫 보고 서두에 "가정: X"로 선언한다. 방식은 pumasi:image의 "딸깍 방식"(선택지 5개 이상, 창의적 대안 1~2개, "자동 판단" 안전망)과 skillers-suda의 "토론 결과에 맞게 동적 구성"을 따른다.

## 0. 절차

1. `raw-input.md`를 `intake-checklist.md`의 필수 4종 + 슬롯 10개에 대조해 **불확실성 목록**을 만든다. 각 항목에 `확정 / 추론 가능(디폴트) / 불명(질문)` 셋 중 하나를 매긴다.
2. `불명` 항목만 아래 은행에서 골라 **우선순위 순으로 최대 4문항씩, 최대 2라운드(총 8문항 이내)** AskUserQuestion으로 묻는다. 텍스트로 질문하거나 A/B/C를 나열하지 않는다.
3. 1라운드 답이 새 불확실성을 만들면(예: "환불 불가"→대체 장치) 2라운드에 넣는다. 2라운드에서도 안 풀린 것은 묻지 않고 플레이스홀더로 진행한다.
4. 같은 질문은 두 번 하지 않는다. 답이 없으면 디폴트 선언 후 진행한다.
5. 답변은 `intake-checklist.md`의 `출처` 열에 `인터뷰 R1-Q2` 형태로 기록한다. 카피의 모든 수치·사례가 여기서 추적된다.

## 1. 우선순위

| 순위 | 불확실성 | 왜 먼저인가 |
|---|---|---|
| P1 | 무엇을 파는가 (M1) | 없으면 아무것도 못 쓴다 |
| P2 | 누구에게 — 좁은 타겟 (M2) | Q1이 성립해야 나머지가 선다 |
| P3 | 고객이 얻는 변화 (M4) | 약속은 AI가 정해줄 수 없다 |
| P4 | 플랫폼 (S9) | 비율·폭·문장 길이가 갈린다 |
| P5 | 증거 자료 유무 (S4) | Q4가 실물이냐 플레이스홀더냐 |
| P6 | 가격·환불 (M3, S7) | Q7·Q8의 문구가 갈린다 |
| P7 | 규제 업종 여부 | 건기식·화장품·의료기기·금융이면 금지 표현 필터 적용 |
| P8 | 산출물 범위·이미지 톤·카피 톤 | 되돌리기 쉬움. 디폴트로 가도 됨 |

## 2. 질문 은행 (options는 상황에 맞게 재작성 — 그대로 복붙 금지)

### Q-타겟 (P2) — "모두"이거나 불명일 때
- question: "이 페이지가 가장 먼저 붙잡아야 할 한 사람은 누구인가요? 첫 화면은 이 사람의 장면으로 시작합니다."
- options: M1·M4에서 **추정한 고객 장면 3개**(각 description에 그 사람이 오늘 겪는 순간 1문장) + "내가 직접 쓸게" + "폭넓게 가고 싶어요 (권장하지 않음 — 첫 화면이 아무에게도 후킹되지 않습니다)"
- 입력에 후기·문의·커뮤니티 글이 있으면 **고객이 실제로 쓴 문장**을 장면 후보로 우선 제시한다(VoC 헤드라인이 실측에서 가장 강했다). 없으면 Claude 추정임을 description에 표기한다.
- 추정 장면을 고르면 `intake-checklist.md`에 "추정→승인"으로 기록한다.

### Q-플랫폼 (P4)
- options: "웹 랜딩페이지 (기본)" / "네이버 스마트스토어 (세로 스크롤형)" / "크몽·탈잉 서비스 상세" / "인스타·스레드 세일즈 캡션" / "자동 판단"

### Q-유입 (P4, 플랫폼과 함께)
- question: "이 페이지에 오는 사람은 주로 어떻게 들어오나요? 첫 화면의 문장 유형이 달라집니다."
- options: "검색해서 들어옴 — 제품을 이미 알고 비교 중" / "광고·SNS 보고 처음 옴 — 문제만 알고 있음" / "선물·추천 링크로 옴" / "반반" / "자동 판단"
- 검색 유입이면 Q1에 카테고리 키워드 + 가격 근접 배치, 광고 유입이면 고민 장면으로 시작.

### Q-증거 (P5)
- question: "고객이 '나도 될까?'를 확인할 실물이 있나요? 후기보다 실제 결과물 화면이 강합니다."
- options: "결과물 스크린샷·사진 있음 (경로를 알려줄게)" / "후기·수치만 있음" / "신제품이라 아직 없음 — [자료 필요]로 표시" / "체험단·베타를 실제로 모집할 계획 있음" / "자동 판단 (있는 것만 쓰고 없는 건 표시)"

### Q-환불·보증 (P6)
- options: "7일 이내 환불 (전자상거래법 기본)" / "환불 불가 — 대신 샘플·미리보기로 불안 해소" / "부분 환불·조건부 (조건을 알려줄게)" / "아직 미정 — 이번엔 [자료 필요]로" / "무료 체험·1회 무료"

### Q-가격 노출 (P6)
- options: "정가만" / "할인가 + 정가 취소선" / "협의·문의" / "미정 — 배지로 표시" / "구독·분할 (구조를 알려줄게)"

### Q-규제 (P7) — 식품·건기식·화장품·의료기기·금융·교육(자격) 신호가 있을 때
- question: "이 제품이 표시·광고 규제 업종에 해당하나요? 해당하면 금지 표현 필터를 켭니다."
- options: "건강기능식품 (인증마크 있음)" / "일반식품·농수산 가공품 (건기식 아님)" / "화장품 / 의료기기 / 금융 / 교육·자격 / 부동산 / 전자제품 (상세 필터 미작성 — 법령 인덱스만 적용)" / "해당 없음" / "모르겠어요 — 보수적으로 필터 켜줘"
- 상세 필터가 있는 업종은 식품·건기식뿐이다(`compliance.md` §1~§3). 그 외 업종은 §6 인덱스 + §7 공통 원칙만 적용하고 보고에 "상세 필터 미작성"을 명시한다.

### Q-산출물 범위 (P8)
- options: "카피만 (가장 빠름)" / "카피 + HTML 시안" / "카피 + HTML + 이미지 필수 4장 (기본)" / "전부 — 이미지 8장" / "자동 판단"

### Q-이미지 톤 (P8)
- options: "화이트 스튜디오 제품컷 (기본)" / "실제 사용 장면 실사" / "플랫 일러스트" / "브랜드 자료 있음 (로고·색 경로 알려줄게)" / "따뜻한 라이프스타일 무드" / "자동 판단"

### Q-카피 톤 (P8)
- options: "담백한 존댓말 (기본)" / "친근한 반말·구어" / "전문가·의사 같은 신뢰 톤" / "유머 섞인 브랜드 보이스" / "자동 판단"

## 3. 스킵 규칙 (묻지 않는 경우)

- 입력에 플랫폼 단어("스마트스토어", "크몽", "랜딩")가 있으면 Q-플랫폼 스킵.
- 입력에 가격·환불 문장이 있으면 해당 질문 스킵.
- 입력에 "카피만", "이미지 없이", "전부"가 있으면 Q-산출물 스킵.
- 사용자가 "질문 없이 알아서" 라고 했으면 라운드 자체를 생략하고 디폴트 표를 보고 서두에 붙인다.
- 가상·연습 상품("가상의 상품으로", "예시로")이면 인터뷰를 생략하고 Claude가 설정한 값을 `intake-checklist.md`에 "가상 설정"으로 기록한다.
