## 1. 형식 결론 — sangse가 만들어야 하는 것

**국내 커머스(컬리·쿠팡·스마트스토어·자사몰) 상세는 "세로로 이어지는 컷 이미지"이고 카피는 이미지 픽셀 안에 있다.** 컬리 레퍼런스는 브랜드 카피부터 주의사항 11항·영양표·원료명까지 전부 이미지다(HTML 텍스트는 플랫폼 안내 1줄). 삼성·LG처럼 판매자 발화를 HTML로 두는 방식은 글로벌 다국어·인터랙션·각주 시스템이 필요한 브랜드 사이트의 것이다.

따라서 sangse의 기본 산출물은 **컷 시트(cut sheet)**다: 폭 1000px(스마트스토어 860 권장폭에 맞춰 축소 가능)의 컷 이미지 12~20장을 세로로 쌓고, 각 컷 안에 헤드라인·서브카피·비주얼이 함께 렌더된다. 단, 레퍼런스가 이미지 안에 넣은 **법정 표시(주의사항·상세정보 표·영양표·원료명)는 HTML 텍스트로 둔다** — 생성 이미지의 작은 글씨 정확도가 낮고, 검색·복사·수정성에서 HTML이 우월하며, 상품정보고시는 플랫폼 입력란이 따로 있기 때문이다. 단일 이미지 제출이 강제되는 플랫폼이면 그 블록만 별도 텍스트 컷으로 추가 생성한다.

## 2. 공통 규칙 (세 이미지형 레퍼런스에서 반복된 것)

### 컷 규격
- 캔버스 폭 1000. 컷 높이는 폭의 0.6~1.4배(600~1,400px). 히어로·페르소나 컷이 가장 길고(1,000~1,400), 목차·구성·CTA 컷이 짧다(600~750).
- 콘텐츠 안전 영역: 좌우 안쪽 여백 55~80px. 중앙 정렬 본문 최대 폭 560(컬럼 710 기준) ≈ 폭의 78%.
- 컷 구분은 **배경색 전환이 기본**(컬리: 레드→연회색→브라운→흰→탄→크림→탄→브라운/오렌지→연회색). 보조로 사선 분할·바탕 위 흰 라운드 카드·"Point N" 배지+헤어라인. 여백만으로 나누는 컷은 없다. 삼성은 정반대(전면 검정, 정렬 전환+140~200px 여백)이나 이미지형에서는 쓰지 않는다.
- 한 컷 = 메시지 1개. 마케팅 컷 텍스트 10줄 이하, 법정 컷만 17줄까지.

### 타이포 (폭 1000 기준)
| 역할 | 글자 높이 | 글자 수 |
|---|---|---|
| 대형 히어로 헤드 | 65~75px | 4~9자, 2행이면 행당 5~9자 |
| 섹션 헤드(Point N) | 42~50px | ≤10자 |
| 소섹션 헤드(TPO·추천 대상) | 28~40px | ≤17자 |
| 서브타이틀(가는 웨이트) | 32~34px | ≤10자 |
| 본문 | 22~26px | 줄당 ≤24자, 2~4줄 |
| 각주·출처·법정 | 18~20px | — |
| 차트 값·캡션 | 14~16px | — |

헤드라인은 공백 제외 4~17자(평균 10.8). 감성 헤드는 2행으로 쪼개 행당 5~9자. 삼성 피처 컷도 헤드 ≤22자·2줄, 본문 ≤5줄이라 상한이 같다.

### 위계·강조
- 서체 위계: 헤드 = 검정 볼드 고딕 또는 캘리그래피(페르소나 1곳만), 서브 = 가는 고딕, 라벨 = 세리프·스크립트.
- 강조는 **세 가지만**: 키워드 볼드 / 브랜드색 스크립트 콜아웃("손쉬운 하루 한 포!") / 아웃라인·반전 박스. 보조로 노란 형광 하이라이트(장면 헤드 강조어), 탄색 라벨 박스(부원료명).
- 숫자: 브랜드색 대형 숫자(목차 원 안 60px), 규격은 대괄호·괄호 세리프 "(10 ml x 30포)". 삼성은 "숫자·단위 같은 크기 + 승자만 컬러". 가격·할인 숫자는 이미지 안에 넣지 않는다(플랫폼 UI 영역).

### 색
- 브랜드 주색 1 + 뉴트럴 3~4(탄/베이지·크림·연회색·브라운) + 포인트 1. 컬리 레퍼런스: 레드 #c8102e / 탄 #d8c4a2·#c4a27a / 크림 #f5efe4 / 브라운→오렌지 #a8785a→#c8622a / 연회색 #f0f0f0.
- 법정 블록은 항상 연회색 단색 바탕 + 검정.

### 비주얼
- 제품 실사(박스+낱개 연출, 손에 든 컷, 쏟아지는 클로즈업), 얼굴 없는 라인 일러스트(TPO 장면·STEP), 원형 라인 아이콘(기능성·추천 대상), 제품 위 사선 컬러 블록. 배경에 떠 있는 제품+밋밋한 그림자는 없다.
- 이미지:텍스트 면적 ≈ 72:28(삼성 피처 컷 실측). 마케팅 컷 텍스트 면적 12~25%, 근거·법정 컷 40~50%.

## 3. 컷 시퀀스 — 레퍼런스 순서와 8질문 매핑

컬리(19컷) 순서: 브랜드 매니페스토 → 리뉴얼 공지 → 제품명 히어로(해시태그) → **타겟 페르소나 선언(33세 대기업 사원)** → **TPO 3장면(출근·미팅·퇴근)** → 크로스셀 → Check Point 목차 3 → Point 1 제형 → Point 2 기능성 5 → 인체시험 I → 인체시험 II → Point 3 부원료 → 섭취 STEP 3 → 추천 대상 2×2 → 제품 구성 → 주의사항 → 상세정보 표 → 영양·기능정보 → 원료명.

| 8질문 | 레퍼런스가 답하는 컷 | 강도 | sangse 컷 시트 기본 배치 |
|---|---|---|---|
| Q1 나를 위한 건가 | 페르소나 선언 + TPO 3장면 + 추천 대상 2×2 (3중) | 강 | 컷 2 페르소나, 컷 3 TPO, 컷 12 추천 대상 |
| Q2 뭘 얻나 | 해시태그 히어로, Check Point 목차, 기능성 아이콘 | 강 | 컷 1 히어로 태그, 컷 5 목차 |
| Q3 왜 이 방식 | Point 1·2·3(제형·원료·부원료) | 강 | 컷 6·7·9 Point 단락 |
| Q4 나도 될까 | 인체시험 카드 2(RCT 출처) — 후기·사례 없음 | 부분 | 컷 8 근거 카드(입력에 자료 있을 때만) + 실물·후기 슬롯 |

| Q6 뭘 받나 | 제품 구성 연출 + 포장 단위 | 강 | 컷 13 구성 |

관찰: 레퍼런스는 Q1~Q6이 두텁고 Q7·Q8이 비어 있다. 플랫폼 구매 UI가 가격·CTA를 담당하기 때문이다. sangse는 Q7을 이미지 컷으로 강화하고, Q8은 플랫폼에 따라 컷 또는 HTML로 둔다.

### 채널 규칙으로 승격
1. **타겟 위치는 채널 문법이다.** 오픈마켓·자사몰은 브랜드 인지 고객 전제라 근거 먼저, 큐레이션 몰(컬리)은 고민 장면 먼저. sangse 기본은 컬리형(8질문 순서 그대로: Q1 먼저)이고, 유입이 브랜드 검색이면 Point 단락을 앞당길 수 있다.
2. **본문 3줄 상한 + 결론 줄 볼드**는 세 채널 공통(컬리 2~4줄). 컷 시트 기본값 = 서브 3줄, 마지막 줄 볼드.
3. **Q8은 본문에서 분리**한다. 프로모션·기한은 시즌마다 교체되므로 별도 컷(자사몰) 또는 플랫폼 UI(쿠팡·컬리). sangse는 C2 CTA 컷을 시트 끝에 두되 파일을 분리해 교체 가능하게 한다.
4. **폭 1000으로 만들고 채널별 축소**를 전제로 글자 최소 크기를 정한다: 쿠팡 780 렌더에서 22px 각주가 17px, 스마트스토어 모바일에서는 그 절반. 이미지 안 최소 글자 24px(폭 1000 기준), 각주는 HTML로.
5. **기능성 문구는 대표 1개를 헤드·해시태그로, 전체 문구는 K7 컷 하단에 원문**(컬리 방식). 쿠팡·자사몰처럼 라벨 스캔에만 두는 것은 판독 불가.
6. **후기가 없으면 인체시험·기업 실적·인증으로 Q4를 채운다** — 세 채널 모두 개인 후기 컷이 없다. 단 sangse는 실적 숫자도 입력에 있을 때만.
